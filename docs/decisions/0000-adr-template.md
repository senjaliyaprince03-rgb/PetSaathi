# ADR 0000: Architecture Decision Record Template

## Status
Proposed / Accepted / Rejected / Deprecated / Superseded

## Context
What is the problem we are trying to solve? What forces are at play? Describe the technical or business context that necessitates this decision.

## Decision
What is the change that we are making? Describe the technical design, framework choice, or architectural shift.

## Consequences
What becomes easier or more difficult because of this change?
- **Positive:** Benefits of this decision.
- **Negative:** Trade-offs, technical debt incurred, or required migrations.
- **Neutral:** Changes to workflow or process that are neither strictly good nor bad.

## Compliance & Security Impact
Does this decision impact our data classification policy, MVP boundary, or require additional security review?
