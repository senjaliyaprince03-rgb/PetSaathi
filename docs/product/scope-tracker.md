# Scope & Feature Tracker

This document differentiates critical defects (required for MVP launch) from scope additions (features to be evaluated post-launch). This prevents feature creep from delaying the MVP release.

## Defect vs. Scope Addition
- **Defect:** Existing functionality is broken, a security vulnerability exists, or a critical MVP requirement (e.g., booking validation) is missing. *Must fix before launch.*
- **Scope Addition:** A new feature, enhancement, or optimization that is not strictly required to facilitate a safe, verified booking. *Must be logged here and deferred until Phase 11 (Post-Launch).*
